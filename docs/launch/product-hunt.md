**Key features**

- Start with a typed interview question and the answer model you choose.
- Transcribe one microphone or playback device locally during a permitted session.
- Use local Ollama, a Claude Console API key, or preview ChatGPT sign-in where eligible.
- Save completed sessions to a local library when you choose.

## Maker's first comment

Hi, I built OpenKeet to make it easier to start interview preparation with one question. I wanted a tool that helps me check how I explain a choice and get ready for the follow-up.

You can type a question after connecting an answer model. If you want to practice with audio, OpenKeet can transcribe a mic or Windows playback device on your PC. Answers can come from a downloaded Ollama model or a supported service you choose. The app has no subscription. Connected services may have their own charges or limits.

The first release focuses on Windows 11 x64. I’d like to hear what happens when someone starts from a clean setup. Which screen made sense immediately, and which one did you have to read twice?

Thanks for trying it. Interview smarter. Answer better.
